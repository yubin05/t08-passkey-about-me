안녕하세요, 김유빈입니다

이 페이지는 클라우드/DevOps 채용 담당자와 팀 동료에게 제가 문제를 어떻게 진단하고 해결해왔는지, 무엇을 만들어왔는지를 보여주기 위한 한 페이지입니다.

소개

게임 클라이언트 개발자로 시작해, 지금은 AWS·Azure 인프라와 DevOps를 다루는 엔지니어로 성장 중입니다.

대표 활동

4인 팀 리드로 AWS-Azure 멀티클라우드 DR 기반 무중단 숙박 예약 플랫폼을 설계·구축했습니다.

  • 팀원 등 타인의 개인정보가 포함된 자료

강점과 근거

강점 1 — 근본 원인을 끝까지 추적하는 트러블슈팅

상황
DR 프로젝트에서 Site-to-Site VPN 터널 연결이 계속 실패함
행동
CloudWatch 로그를 분석해 StrongSwan IKE 협상 방식이 Azure VPN Gateway와 호환되지 않음을 특정하고, LibreSwan으로 교체 후 Azure 호환 방식으로 재구성
결과
VPN 터널 연결이 안정화됐고, 이후 장애 발생 시 로그·근본 원인부터 확인하는 습관이 생김

강점 2 — 사전 합의로 협업 비용을 줄이는 팀 리딩

상황
4인 팀 프로젝트에서 팀장으로 인프라 가동·중단 시점과 회의 일정을 조율해야 함
행동
인프라 가동 시간을 팀원들과 미리 합의해 필요한 시간에만 가동하고, 회의는 사전 공지 후 회의록으로 공유. Terraform 리소스도 IAM·보안그룹·로그그룹 단위로 모듈화해 가독성을 높임
결과
불필요한 소통 비용이 줄었고, 팀원 피드백이 반영된 정리된 인프라 구조를 완성함

강점 3 — 단계적으로 새 기술을 익히는 학습력

상황
게임 클라이언트 개발자에서 클라우드/DevOps 엔지니어로 직무를 전환하기로 함
행동
네트워크 기초(개인 프로젝트) → AWS 클라우드 실전(팀 프로젝트) → Kubernetes 심화(EKS 개인 프로젝트) 순으로 스스로 학습 단계를 설계하고, 매 단계 Terraform·GitHub Actions·ArgoCD를 직접 적용
결과
AWS Certified Solutions Architect - Associate 자격을 취득하고, EKS 컨테이너 오케스트레이션 개인 프로젝트를 완주함
